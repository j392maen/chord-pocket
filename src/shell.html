CP-7 GUIDEChord Pocket の使い方

7つのキー

キーは、選んだキーとスケールのダイアトニックコード（Ⅰ〜Ⅶ）です。どれを押してもきれいに響き合うので、適当に押しても曲になります。

3つのボタン

灰 KEYキー、スケール、全体オクターブ、スティックモード、本体カラー
黄 SOUND音色22種とユーザー音源、リバーブ、ディレイ、コーラス、フィルターなどのエフェクト
赤 MODE演奏モード、テンポ、タップテンポ、モードごとの設定
メニュー内スティック ←→ で項目、↑↓ で値。タップで実行（または値をランダムに）。画面の左右端・下半分を直接タップしても操作できます
ホイール左右にこすって音量

キーを押しながら倒す

キーを押すと、スティックの周りに「その方向へ倒したときに鳴る和音」が表示されます。「M⇄m」はメジャーとマイナーの入れ替え、「/」の左はメジャー系、右はマイナー系のキーで鳴る和音です。

DEFAULT

↖aug↑M⇄m↗7←m / dim・基本→maj7 / m7↙6 / sus2↓sus4↘maj9 / m9

EXTENDED

↖m7♭5↑M⇄m↗9←7sus4・基本→add11↙add9↓7♯9↘m11

CHROMATIC

↖maj7♯11↑m(maj7)↗13←m7♭5・基本→6/9↙7♭9↓maj13↘7alt

CHROMATICでは、キーを押さずに ←→ でキーを半音ずつ移動します。

PLAY和音をそのまま鳴らす
STRUM低い音から順にずらして鳴らす（SLOW 120ms・MED 80ms・FAST 40ms）
LEADルート音の単音。押し替えるとグライド
DRONE離しても鳴り続ける。同じキーをもう一度押すと停止
ARPアルペジオ。型6種、速さ1/1〜SWING 16th、重ね方3種
REPEAT押している間、テンポに合わせて刻む
SEQキーでステップ入力、←→ で移動、↑ で4ステップ追加（最大16）、↓ で4ステップ削除、タップで再生
DRUMキック、スネア、クラップ、ハット、タム、ベル、シンバル。キット7種
LOOPSドラムループ7スタイル。キーを押しながら ↑↓ で8バリエーション
HIRO流れてくる度数を小節の頭で押すリズムゲーム。次に押すキーが光ります
EAR鳴った和音を当てる耳トレ
MIXERキー1〜6でトラックのミュート。押しながら ↑↓ 音量、→ ソロ、← 消去

SEQ と LOOPS は、再生中に別のモードへ移ると空きトラックへ自動で録音されます。

1本目

スティックをタップすると長さ選択（←→ でFREEか1〜8小節）。もう一度タップすると4拍カウントのあと録音が始まります。FREEはタップで止めた長さ、小節指定は自動で止まります。

2本目以降

タップですぐ録音が始まり、ループ1周で止まって次のトラックへ進みます。音色を変えてから重ねられ、各トラックは録音したときの音色で鳴ります。最大6トラック。

消す

スティックを長押しで全消去。1本ずつ消すときは MIXER で。

画面の表示

キー・スケールモードテンポと拍ループ位置（細い線）いまの和音と構成音・波形PROG：弾いた和音の履歴鍵盤：鳴っている音トラック 1〜6ヒント

画面左下の 1〜6 の箱がトラックです。塗りつぶし＝再生中、枠だけ＝録音済み（ミュート中）、うすい枠＝空、赤＝録音中。上部の細い線はループの再生位置です。
